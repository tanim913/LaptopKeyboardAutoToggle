Silence your faulty laptop keyboard the moment your wireless dongle connects.

Windows and Linux block ordinary tools from disabling built-in keyboards. LaptopKeyboardAutoToggle uses kernel-level suppression and serio bus unbinding to automatically turn off malfunctioning laptop keyboards with zero latency, zero polling, and guaranteed recovery.

Why other solutions fail on laptop keyboards

        
Windows flags internal PS/2 keyboards as critical system devices, breaking Device Manager and ordinary scripts.

      


      

        

          

            ×
            
Standard PnP & pnputil

          

          

            Windows assigns the flag CM_DEVCAP_NONDISABLEABLE to internal laptop keyboards. Running pnputil /disable-device fails with:
          

          

            Failed to disable device:
Cannot disable critical system device.
          

          
In Device Manager, the "Disable device" option is completely greyed out.

        


        

          

            ✓
            
Dual-Engine Architecture

          

          

            LaptopKeyboardAutoToggle bypasses the Device Manager block by filtering scancodes at the kernel driver layer:
          

          
    
            
  • 
              Windows Engine: Uses an Interception class filter driver to discard internal keyboard scancodes with 0ms latency while letting your wireless dongle type freely.
            
    • 
            
  • 
              Ubuntu / Linux Engine: Leverages the native Linux kernel serio bus unbinding (/sys/bus/serio/drivers/atkbd/unbind) without needing third-party drivers.

Get started in two clicks

        
Choose your operating system to see the setup process.

      


      
      

        
        
      


      
      

        

          

            
1

            
Extract the zip

            
Download LaptopKeyboardAutoToggle-win-x64.zip from GitHub and unzip the folder anywhere on your PC.

          


          

            
2

            
Double-click ONE-CLICK-SETUP.bat

            
Click "Yes" on the Windows Administrator prompt. It automatically registers the driver, schedules the elevated logon task, and launches the app.

          


          

            
3

            
Reboot once

            
Restart your laptop once so Windows kernel loads the keyboard filter. From then on, automation is 100% hands-free!

          

        


        

          

            
Built-in Emergency Recovery

            
If your wireless keyboard battery dies while the dongle stays plugged in, you are never locked out: right-click the system tray icon with your touchpad and click "Turn Internal Keyboard ON", or press Ctrl + Alt + Shift + F12.

          

        

      


      
      

        

          

            
1

            
Download the .deb

            
Download laptop-keyboard-auto-toggle_1.0-1_all.deb from GitHub Releases.

          


          

            
2

            
Double-click to install

            
Open it with Ubuntu Software Center and click Install, or run in terminal:

            

              sudo dpkg -i laptop-keyboard-auto-toggle_1.0-1_all.deb
              
            

          


          

            
3

            
Done

            
The indicator appears in your Ubuntu top bar and automatically silences the internal keyboard on dongle connection.
